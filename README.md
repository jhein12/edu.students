# Edustudents

## Objetivo
Crear una plataforma educativa que permita a los estudiantes compartir apuntes, resolver dudas y organizar sus actividades académicas.

## Problema que resuelve
Muchos estudiantes no tienen acceso a material de estudio organizado ni apoyo académico inmediato.

## Público objetivo
Estudiantes de colegio y universidad.

## Descripción de la plataforma
Edustudents es una plataforma web donde los usuarios pueden subir apuntes, hacer preguntas, acceder a recursos educativos y organizar sus tareas.
